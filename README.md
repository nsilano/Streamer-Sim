# Stream Empire

Streaming-service management sim for iOS 17+ (SwiftUI, no dependencies).
See `CLAUDE.md` for the design and build phases.

```
brew install xcodegen
xcodegen generate
open StreamEmpire.xcodeproj
```
Engine tests without Xcode: `swift test`. Play on your phone: `docs/PLAY_ON_PHONE.md`. TestFlight setup: `docs/TESTFLIGHT.md`.
